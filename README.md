# Python Finance Tracker

A simple Python finance tracker that allows users to record income and expenses, view transactions within a date range, calculate financial summaries, and visualize transactions using daily and monthly graphs.

## Features

- Add income and expenses
- Store transactions in CSV
- Search transactions by date range
- Calculate total income
- Calculate total expenses
- Calculate net savings
- Daily income/expense graph
- Monthly income/expense graph

## Requirements

- Python
- Pandas
- Matplotlib
